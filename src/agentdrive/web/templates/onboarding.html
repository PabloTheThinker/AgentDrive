What this is

Agent Drive is a substrate-grounded workspace for your AI agents. The sidebar chat talks to your agent — wherever it runs — over HTTP+SSE. Bring your own runtime. If you don't have one yet, you can wire the sidebar to a model provider as a fallback.

This wizard takes you through:

  • Creating an agent record (id, label, optional identity).
  • Telling Agent Drive how to reach your agent (or a model).
  • Verifying the connection and opening chat.
